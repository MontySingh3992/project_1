# Logic Gates using Verilog in Xilinx Vivado

## Project Overview
This project implements basic digital logic gates using Verilog HDL in Xilinx Vivado.

The project demonstrates the design and simulation of:
- NAND Gate
- NOR Gate
- NOT Gate

## Tools Used
- Xilinx Vivado 2023.2
- Verilog HDL
- Windows 11

## FPGA Device
- Artix-7 (xc7a35tcpg236-1)

## Project Files
```
logic_gate.v      // Verilog source code
stimuli.v         // Testbench
project_1.xpr     // Vivado project
README.md
```

## Features
- Verilog implementation of basic logic gates
- Functional simulation
- RTL synthesis in Vivado
- Beginner-friendly project

## How to Run
1. Open `project_1.xpr` in Xilinx Vivado.
2. Run **Simulation**.
3. Verify the output waveforms.
4. Run **Synthesis**.

## Learning Outcomes
- Understanding Verilog modules
- Writing a testbench
- Running simulation
- RTL synthesis in Vivado
- Basic digital logic design
